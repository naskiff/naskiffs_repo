# Characters

## Stats
- Strength
	- Carry capacity, <span style="color:rgb(164, 111, 206)">damage</span>, musculature. <span style="color:rgb(255, 136, 0)">At zero, can't even get out of bed until healed (naturally or magically)</span>
- Constitution
	- Endurance (effort), and resistance to poison, disease, illness. <span style="color:rgb(164, 111, 206)">Affects HP and recovery speed.</span> <span style="color:rgb(255, 136, 0)">At zero, character dies.</span>
- Size
	- Height and weight. Human has Size 8. <span style="color:rgb(164, 111, 206)">Affects HP and damage.</span> <span style="color:rgb(255, 136, 0)">At zero, atrophied, bedridden.</span>
- Dexterity
	- Agility, balance, reflexes, speed, gracious movements. <span style="color:rgb(164, 111, 206)">Affects Action Points (AP) and Initiative.</span> <span style="color:rgb(255, 136, 0)">At zero, paralyzed.</span>
- Intelligence
	- Cognitive. Low INT can mean unimaginative rather than stupid. 7 or less, spontaneous/emotional. <span style="color:rgb(164, 111, 206)">Affects Action Points (AP) and Initiative.</span> <span style="color:rgb(255, 136, 0)">At zero, vegetable.</span>
- Power
	- Distinctive towards gods and supernatural. Spirit/magic potential. <span style="color:rgb(164, 111, 206)">Affects mana and luck.</span> <span style="color:rgb(255, 136, 0)">At zero, no willpower.</span>
(Charisma would affect XP gain, but I'm not interested in XP, so I don't want Charisma as a stat)

## Attributing stats
- 64 points total
- Respect the minimal/maximal values for the character's race.

## Characteristics
- Initiative = (DEX+INT)/2

# Combat

## Styles
Develop styles according to nations, professions, social status, culture, schools, etc.
Each style focuses on 3-4 weapons.
Weapon categories <span style="color:rgb(71, 215, 186)">can optionally</span> be allowed: swords, blunt weapons, etc.
Weapons can be unusual, like siege weaponry.
Styles are not only about weapons, but also about group combat methods. (Tight formation, horseback)

## Weapons
- 2-handed means more range and damage, but if lost, heavy disadvantage.
- Shield best defensive weapon because works against heavy and ranged.
- Dual is most range-flexible, also works if one weapon lost/broken.
- Ranged avoids parries/counter-attacks.
- Unarmed best within close range. Can use any limb except chest.

## Using weapons without training
- Very different (Diff weight, length, method, size)
	- Use base value of combat styles (Str+Dex)
- Moderately different (1h vs 2h)
	- Same style +2 difficulty levels
- Rather similar (short sword vs saber)
	- Same style +1 diff level
- Similar (Scimitar vs saber)
	- Same style.
- Known + Unknown (Unknown + shield)
	- Same style +1 diff level


## Combat
- 1 round = 5 seconds
- Initiative = 1d10 + initiative bonus. Ties = simultaneous.
- Initiative penalty = Enc of all armor pieces / 5 rounded up. (See <span style="color:rgb(71, 215, 186)">armor p.62</span>)

## Turns
- On each turn, you can use up your Action Points to use actions.
- Actions can be proactive or reactive.
- Can only attack when you have initiative.
- If no proactive action chosen, defaults to "Hesitate"
- Reactive actions; as many as APs available per round. Only one against each threat.
- The initiative <span style="color:rgb(71, 215, 186)">cycle</span> continues until nobody has any AP left. Then, next round begins.

## Actions
- Attack
- Change distance (See <span style="color:rgb(71, 215, 186)">p.103</span>)
- Hesitate (Lose your turn)
- Fight back (against a Special Effect)
- Manoeuvre (Dodge roll vs multiple enemies. Those who fail, can't attack you this turn)
- (un)Mount - Up/down a mount (horse, etc.) Might take more than one turn for big mounts. (<span style="color:rgb(71, 215, 186)">p.102</span>)
- Rearm (Ready arrow, reload, or 2 turns to pick up dropped weapons; 1 pick + 1 return to stance)
- Brace for impact (SIZE +50% against push attacks (<span style="color:rgb(71, 215, 186)">p98, p102</span>), 2x SIZE against Knockback FX.) 
	- Lost on movement.
- <span style="color:rgb(255, 136, 0)">Delay</span> (Ready a reaction. If no enemy action came this cycle, counts as Hesitate.)
- Move (When disengaged. Any distance GM feels OK. Can be acrobatics.)
	- Next turn, no further movement action is needed, can attack.
	- *This is never needed against a nearby opponent.*
- Take Cover (p.78 for armor points and inanimate object HP)
- Get up (If not engaged, this succeed. Else, Brute Force or Athleticism opposition test against opponent.)
- Use Magic (Might need +rounds. Unleashed at any time when ready.)
- Hold Magic (When a spell is ready, delay using it now. Can use it as Counterspell reaction freely.)

## Reactions
- Counterspell (1 round cast time. Counters any spell, even area spells.)
- Dodge (Dive or roll away. Leaves you on the ground.)
- Interrupt. (Only available after <span style="color:rgb(255, 136, 0)">Delay</span>. Only for preventative measures.)
- Parry

## Free Actions
(Costs no AP)
- Analyze Situation (If not in combat, perception check.)
- Guard (Specific area, like the head. Parries perfectly. Shields can block multiple areas. <span style="color:rgb(71, 215, 186)">p.102</span>)
- Drop weapon
- Talk (Short phrases, a round is 5 seconds.)
- Signal (If you are not in combat and the target can hear or see you.)
- Use Luck Token

## Range & Size
<span style="color:rgb(0, 176, 80)">Touching</span>, <span style="color:rgb(71, 215, 186)">Short</span>, <span style="color:rgb(0, 112, 192)">Medium</span>, <span style="color:rgb(164, 111, 206)">Long</span>, <span style="color:rgb(255, 136, 0)">Very Long</span>.
(<span style="color:rgb(0, 176, 80)">Fists</span>, <span style="color:rgb(71, 215, 186)">Shortsword</span>, <span style="color:rgb(0, 112, 192)">Broadsword</span>, <span style="color:rgb(164, 111, 206)">Longsword</span>, <span style="color:rgb(255, 136, 0)">Pike</span>)
Reach is 100% effective up to 1 weapon range away.

<span style="color:rgb(0, 176, 80)">Small</span>, <span style="color:rgb(71, 215, 186)">Medium</span>, <span style="color:rgb(0, 112, 192)">Large</span>, <span style="color:rgb(164, 111, 206)">Very Large</span>, <span style="color:rgb(255, 136, 0)">Enormous</span>.
Creatures can be beyond these human ranges.
Natural attacks from creatures have similar functions. (<span style="color:rgb(71, 215, 186)">p.218</span>)
